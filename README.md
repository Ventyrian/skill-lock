# Skill Lock Plugin
This is my first plugin, and it was designed for use with snowflake accounts that impose self restrictions to their skills or maximum skill level. I took inspiration from SlayerScape, and many other unqiue ironman accounts. I hope to use this plugin myself after I finish my TaskLocked ruleset and maybe make a plugin for that. 

## Main Features
#### NOTE ALL FEATURES ARE PURELY COSMETIC AND DO NOT CHANGE THE ACTUAL VALUES OF YOUR SKILLS OR EXP
- Ability to grey out skills and have them "locked"  (right click option: Lock / Unlock, will overlay lock icon and grey out skill)
- Ability to lock skills to a certain static level (right click option: Set, will peompt the user to input a level and overwrite skill guide values with the input)
- Ability to preview real level (hovering over a skill and holding shift will reveal the actual level)
- In addition to all in-game context menus the plugin has all controls in its config panel as well, if you want to quickly change various settings 
  - (Note if changing the lock state or levels via the in game context menu the configuration menu is not updated until it is closed and reopened)
- Sound effects for locking and unlocking skills
- Glow effect when unlocking skills
- Now works with all interface options: (Fixed - Classic Layout, Resizeable - Classic Layout, Resizeable - Modern Layout)
